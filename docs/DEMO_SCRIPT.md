# 5-Line Phone Demo Script

Use this concise 5-step walkthrough when presenting the preview on a mobile device:

1. **First Glance**: "Notice how quickly it opens and that our phone and 'Book a test' buttons appear immediately without scrolling."
2. **Interactive Tests**: "Tap any test row to see how smoothly it expands with what is included and an instant booking button."
3. **One-Tap WhatsApp**: "When you tap 'Book this test', WhatsApp opens with the exact test name already filled in, ready to send."
4. **Doctor Hours & Location**: "Patients can see consulting doctor schedules and tap 'Open in Maps' to get instant directions."
5. **Fast & Secure**: "There are no slow forms or logins, zero risk of data leaks, and it loads in less than a second on any network."
