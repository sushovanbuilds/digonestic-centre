# CONTENT_RULES.md

## Voice
Plain, calm, sentence case, active voice. Buttons say the action: "Book a test", "WhatsApp us", "Open in Maps", "Request on WhatsApp". Same action keeps the same name everywhere.

## Banned (never write)
NABL, ISO, accredited, certified, verified, leading, best, trusted by, state-of-the-art, advanced, same-day, 24x7, "report in N hours", painless, affordable, discount, offer, star ratings, parameter counts ("64 parameters"), "cold-chain", "temperature monitored", "trained phlebotomists", "records", real-looking times.

## Placeholder bank
Test name 1..6 / Short description placeholder / Included item placeholder / Health package A, B, C / Package description placeholder / Doctor name placeholder / Speciality placeholder / Days placeholder / Hours placeholder / Address line 1, 2 / Review placeholder / [CENTRE NAME] / [AREA, TOWN]

## Required notices
- "Sample content" tag on the tests and packages section.
- Hero line: "Sample preview. Content is placeholder."
- Footer: "Concept preview. Not the official website."
- Contact: "Opens WhatsApp with a ready message. Nothing is stored here."
- Reviews empty state: "Review placeholder" x3. No names, quotes, or stars.

## Trust points (allowed, cannot be false)
1. Tests and doctor consultations under one roof
2. Booking requests by WhatsApp
3. Simple, readable layout
4. Easy to find (address and map link)
